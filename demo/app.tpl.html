🍔 这不是假的菜单

页面里的 70 多个早餐 SKU 与价格，是 2026-10-22 07:56 通过麦当劳官方 MCP 在门店 1450104 实时拉取的快照（query-meals）；「麦言麦语」的 300 句也与脚本内置数据完全一致，按日期 md5 定位，同一天看到的是同一句。

真实下单发生在 WorkBuddy 里：定时自动化触发 → 调用官方 MCP 核价建单 → 把付款提醒推给你。浏览器里无法安全地持有你的授权令牌，所以这个页面的「建单 / 付款」是本地模拟，只为让你摸到真实手感。

⚙️ 三步就能自己用（WorkBuddy 里）

  • ① 安装 把仓库里的 mcd-breakfast-alarm 目录放进 WorkBuddy 的 skills 目录，配置麦当劳 MCP（见仓库 mcp-config.example.json）；
  • ② 设置 对它说「早餐想吃板烧，20 块以内，7 点 20」，它模糊匹配后帮你定好；
  • ③ 交给闹钟 建两个自动化：20:00 确认、次日 07:20 下单。之后你什么都不用做。
# 说一句话就能设定（模糊匹配 + 价格区间）
python scripts/search.py "板烧" --store-code 1450104 --min 10 --max 20
python scripts/prefs.py  set --store-code 1450104 --time 07:20 \
        --meal 9900003457:1 --days weekdays
# 到点核价建单（先预演，不真下单）
python scripts/fire.py --dry-run
诚实边界

麦当劳 MCP 没有「预约下单」接口。所以它做的是到点现场建单 + 付款提醒，不是提前锁单；待支付订单 15 分钟未付自动过期，钱不会扣。这是这个方案的安全垫，也是它敢「先替你订上」的底气。
