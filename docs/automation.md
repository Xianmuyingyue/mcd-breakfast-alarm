# 定时自动化配置（默认不开启，需手动添加）

> "早餐闹钟"靠 **两个 WorkBuddy 定时自动化**配合：
> **晚上问一句（默认订）→ 早上到点建单 + 付款提醒**。
> 默认**不会自动开启**，需要时在「自动化」面板手动新建。

---

## ① 晚间确认（20:00）

**作用**：每晚问一句"明天订不订"，让用户有机会改套餐或取消；**不回答 = 默认订**。

**触发**
```
FREQ=DAILY;BYHOUR=20;BYMINUTE=0
```

**Prompt（粘贴）**
```
读取本项目 `python scripts/prefs.py show` 的配置。
用一句话提醒用户："明天 HH:MM 的早餐，默认：<门店> <套餐>，金额约 ¥X，要改或不订吗？"
- 如果用户回复"不订 / 取消 / 别订"：运行 `python scripts/prefs.py skip --date <明天日期 YYYY-MM-DD>`，并确认"已取消明天的早餐"。
- 如果用户回复要改（换套餐/换时间）：按新需求重新执行 prefs.py set，并回读确认。
- 如果用户没回复：什么都不做，默认按原配置在次日下单。
```

---

## ② 早晨下单 + 付款提醒（07:20）

**作用**：到点建「待支付」单并提醒付款；若昨晚已取消则跳过。

**触发**
```
FREQ=DAILY;BYHOUR=7;BYMINUTE=20
```
> 时间与 `prefs.py` 里的 `--time` 保持一致，建议比到店时间提前 10–15 分钟。

**Prompt（粘贴）**
```
在本项目目录运行 `python scripts/fire.py`，把输出原样发给用户。
- 若输出"今天已取消/跳过"：告诉用户今天不订。
- 若输出"600039 今日下单次数已达上限"：如实告知明天再试。
- 若输出"餐品不在售"：提示用户更新套餐。
不要代替用户付款，只提醒去麦当劳 App「我的订单」付款。
```

---

## 前提
- WorkBuddy 保持登录、能收到消息/通知（手机端开通知权限）；
- `prefs.json` 已设置（`python scripts/prefs.py show` 能看到店/时间/套餐）；
- MCP 连接器 `mcd-mcp` 已启用、Token 有效。

## 安全垫
- 下单只是「待支付」，**不扣款**；
- 15 分钟不付款自动过期 = **自动取消**；
- 只有用户明确说"不订/取消"，才会用 `skip` 跳过；否则默认订。
